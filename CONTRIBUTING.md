# Feedback and contributions

This repository hosts the public Windows beta, documentation, and feedback. The application source is maintained separately.

Use [Issues](https://github.com/triple6xseven/zxc/issues) for reproducible bugs. Include the app version, Windows version, steps to reproduce, and expected and actual results. Use [Discussions](https://github.com/triple6xseven/zxc/discussions) for questions and ideas. Small pull requests that improve the public documentation are welcome.

Use loopback or traffic you have permission to test. Remove private endpoints, tokens, and packet payloads before sharing diagnostics. For a security issue, follow [SECURITY.md](SECURITY.md).
