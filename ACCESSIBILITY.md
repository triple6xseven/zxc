# Accessibility

ZxcLagLab lets you adjust interface text size and font, choose a theme, and configure shortcuts. The overlay has independent scale and opacity controls.

Accessibility testing for the Windows beta is still limited. If a control is hard to read, unreachable from the keyboard, or unclear with assistive technology, [open an issue](https://github.com/triple6xseven/zxc/issues). Include the beta version, the affected screen, and the Windows display scaling or assistive technology you used, if relevant.
