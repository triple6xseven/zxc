# Security policy

Security reports for the latest public beta are welcome. Go to the repository’s [Security page](https://github.com/triple6xseven/zxc/security) and use **Report a vulnerability** if available. If that option is unavailable, open an issue asking for a private reporting channel without including vulnerability details or sensitive data.

Include the affected version, impact, and the minimum steps to reproduce using a local or authorized test setup. Avoid attaching raw captures or credentials unless you have arranged an appropriate private channel.
